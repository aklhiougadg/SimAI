## 后续实验追踪方式

具体参数应逐段核对“实验配置/环境变量 → 解析 → 属性或成员 → 运行条件 → 状态更新 → 输出”。例如 EWMA_GAIN 即使有效读取，如果该次运行没有ECN反馈，吞吐没有变化也不能证明参数失效；还要验证标记、ACK反馈、alpha更新和发送节奏。
